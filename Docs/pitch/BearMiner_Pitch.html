BearMiner06

Traceability by design

No invented people, roles or projects.

VERBATIM GATE

Quote or drop

Each extracted item needs a quote found in the source (exact or ≥ 85% word match). Unsupported items are dropped and listed.

CLOSED CHOICE

No free-form people

The judge can only select candidate IDs it was given; each result keeps its source URLs.

HONEST GAPS

“No reliable match”

Below threshold, the system says so instead of guessing. Thin pages are marked insufficient.

PROVENANCE

Verified location only

Bern presence earns points only from a source, JSON-LD, imprint or Wikidata — never model memory.

SAFE INPUT

Injection defence

Web text is wrapped as untrusted data; sentences addressed to an AI are removed.

FAIR REACH

No size bias

No institutional quota, recency bonus or mention-count boost in ranking.

Sovereign · affordable · extensible

Runs on Bern's terms, air-gapped if needed.

Apertus v1.5 on an on-premise or Swiss-cloud endpoint. SQLite and Python — no foreign closed service at runtime.

Low cost

Crawling and scoring need no GPU. LLM answers are cached, so re-runs are instant and identical.

Extensible
